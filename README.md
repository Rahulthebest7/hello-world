# hello-world
This repository contains a simple Python program that prints "Hello, World!".

## Running the code
To run the program, navigate to the repository's root directory and execute the following command:
```bash
python hello.py
```

## C++ Hello World

This repository also contains a simple C++ program that prints "Hello, World!".

### Compiling and Running the C++ code
To compile the C++ program, you'll need a C++ compiler (like g++). Navigate to the repository's root directory and execute the following command to compile:
```bash
g++ hello.cpp -o hello_cpp
```
After successful compilation, run the program using:
```bash
./hello_cpp
```
